Pullbell vs Gitify vs Octobox: GitHub notification tools compared

There are several ways to keep up with GitHub notifications. This is a fair look at GitHub's own inbox, Pullbell, Gitify and Octobox: what each is for and when you would pick another one.

GitHub's own notifications

The built-in inbox is the source of truth for the others. It handles subscriptions, filters, saved items and mobile push through GitHub Mobile. Its weakness for many people is attention: you have to go to it, or rely on email. If it already works for you, you do not need anything else.

Pullbell

Pullbell is a macOS-only menu bar app that sorts every event into needs you or FYI. Only the first kind raises a banner. It adds things the plain notification list does not give you: banners when your PR becomes ready to merge or gets a conflict, a failed deploy alert, a daily digest of waiting review requests, and lists of your open PRs (with CI and review state) and PRs waiting for your review. It has a keyboard-driven queue (⌃⌘G) and lets you pick which repos or teams to watch. It polls on an interval (default 3 minutes). It is free (MIT), has no server of ours and keeps the token in the Keychain. It does not run on Windows or Linux.

Gitify

Gitify is an open-source app that shows GitHub notifications from the menu bar or system tray, and it runs on more than one operating system. If you use Windows or Linux, or move between machines, that is the main reason to choose it. For its current options, such as filters and GitHub Enterprise support, see its own README.

Octobox

Octobox is an open-source web app for working through GitHub notifications as an inbox: you can search and filter, then archive, star or mute in bulk. You can use a hosted instance or run your own. It is a triage tool you open on purpose rather than something that rings in the corner of your screen, so it suits large, busy inboxes better than a "tell me when it is my turn" workflow.

How to choose

  • You are on a Mac and review requests slip past you: try Pullbell.
  • You are not on a Mac: Gitify or Octobox.
  • Your inbox has thousands of items and you triage in batches: Octobox.
  • You are happy with email and the web inbox: stay with GitHub.

They can be combined. Pullbell marks an item as read on GitHub when you mark it done, so the web inbox stays tidy. See also reducing GitHub notification noise. Download Pullbell from the latest release.

Frequently asked questions

Is Pullbell a Gitify alternative?

For Mac users, yes: both show GitHub notifications in the menu bar. Pullbell is macOS-only and sorts events into needs-you and FYI, with banners only for the first. Gitify runs on more platforms.

Is Pullbell a replacement for Octobox?

Not exactly. Octobox is a browser-based inbox for bulk triage. Pullbell is a menu bar app that tells you when something needs you. Some people use both.

Does Pullbell replace the GitHub notifications page?

No. It uses the same notifications from GitHub's API, and marking an item done in Pullbell also marks it read on GitHub. The GitHub inbox remains available.

Which one is free?

All of them can be used for free. Pullbell is MIT-licensed. For the others, check their own pages for licences and hosting options.
