Pullbell
Features Install GitHub

Your GitHub inbox, in the menu bar.

Pullbell rings for the things that need you: review requests, comments and reviews on your pull requests, replies, mentions, a PR that just became ready to merge or got a conflict, a failed deploy. Everything else waits in a quiet FYI list. No more review requests lost in email.

Download for macOS View source

Free and open source (MIT). macOS 13 or newer, Apple silicon and Intel.

Rings only when it's you they need

Each GitHub event gets a kind. The ones that need you raise a macOS banner and count towards n; the rest go to the FYI list. Any kind can be turned down to FYI in Settings.

  • 👀
    Review requesteddirectly or through one of your teams
  • 💬
    Comments & mentionsa person comments on your PR or @-mentions you
  • ↩️
    Repliesin a review thread you took part in
  • ✅
    Approved / changes requestedreviews on your PRs
  • 🚀
    Ready to mergeapproved, checks green, no conflict, not a draft
  • ⚠️
    Conflictyour PR just stopped being mergeable
  • 🔥
    Deploy faileda deploy/release workflow failed on a watched default branch
  • 📋
    Daily digestreview requests still waiting on you (off by default)
  • 🤖
    Bots & everything elseFYI, no banner
🤫

Quiet by design

Your own comments, reviews and pushes never ring. A burst of comments on one PR is one banner.

⌨️

Keyboard first

⌃⌘G opens a searchable queue, ⌃⌘P your PRs and the ones waiting for your review. ⏎ opens and marks done.

🎯

Watch what matters

Everything, or only your teams' repos plus any you add. Muted repos are always ignored.

🔒

Private

Talks only to GitHub's API. Your token lives in the macOS Keychain. No account, no tracking, no server of ours.

🌐

Your browser, your profile

Open links in the default browser, a specific one, or a specific Chrome profile.

🔄

Updates itself

Signed updates in the background, installed when no window is open.

Install

About a minute. Needs macOS 13 (Ventura) or newer, on Apple silicon or Intel.

  1. Download the DMG

    Get Pullbell_x.y.z_universal.dmg from the latest release on GitHub, open it and drag Pullbell to Applications.

  2. Clear the quarantine flag, once

    Pullbell is a free side project, so it isn't notarized by Apple (that needs a paid developer account). macOS therefore refuses to open it the first time and may call it "damaged". Run this once in Terminal and it opens normally from then on, updates included:

    xattr -dr com.apple.quarantine /Applications/Pullbell.app

    It only removes the "downloaded from the internet" mark from this one app. The source is on GitHub if you'd rather build it yourself.

  3. Open it and sign in

    A bell appears in the menu bar and a welcome window walks you through it: sign in with GitHub (a short device code, no password typed into Pullbell), choose what to watch, allow notifications, start at login.
