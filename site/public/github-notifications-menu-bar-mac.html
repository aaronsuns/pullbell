GitHub notifications in the Mac menu bar

GitHub has a web inbox, email and a phone app, but nothing that lives in your Mac menu bar. Pullbell is a free, open-source menu bar app that puts your GitHub notifications there and only rings for the ones that need you.

What a GitHub menu bar app should do

The problem with GitHub notifications is not that there are too few, it is that there are too many of one kind and too easy to miss of another. A review request that someone is waiting on looks the same in email as a bot comment. A menu bar app earns its place only if it can tell those apart, and keep the count somewhere you glance at all day.

Pullbell shows a count like 3+5 next to a small bell: 3 things need you, 5 are for your information. Click it and you see the newest items that need you. Click an item and it opens in your browser and is marked as read on GitHub. When nothing needs you the menu says so (for example Nothing needs you · 12 FYI).

Which GitHub events ring a banner

Each notification gets a kind. These raise a macOS banner by default:

  • Review requested, directly or through one of your teams.
  • Comments on your pull request and replies in a review thread you took part in.
  • Mentions when a person @-mentions you.
  • Approved and changes requested reviews on your PRs.
  • Ready to merge: your PR is approved, checks are green, there is no conflict and it is not a draft.
  • Conflict: your PR just got a merge conflict.
  • Deploy failed: a workflow whose name matches deploy|release|publish failed on the default branch of a watched repo.

Bots and everything else go to the FYI list without a banner. Your own comments, reviews and pushes never ring, and a burst of comments on one PR becomes a single banner. You can turn any kind down to FYI in Settings, and nothing is ever dropped, only quieted. There is also an optional daily digest of the review requests still waiting on you (off by default).

Open the queue with a keyboard shortcut

Press ⌃⌘G for a searchable queue of every item, needs-you first. Type to filter by repo, person or text, move with the arrow keys, press ⏎ to open and mark done or ⇧⏎ to mark done without opening. ⌃⌘P opens a list of the PRs waiting for your review and your own open PRs, with CI and review status. ⌃⇧⌘G refreshes now. All three can be changed in Settings.

How Pullbell gets your notifications

Pullbell talks directly to GitHub's API with your own token and polls every 1, 3, 5 or 10 minutes (default 3). That means banners arrive within a few minutes, not instantly. You sign in with GitHub's device flow: Pullbell shows a short code, you approve it on GitHub, and the token is stored in the macOS Keychain. It asks for the notifications, repo and read:org scopes. There is no server of ours in between and no account to create.

The first sync after you sign in is silent, so you do not get a hundred banners for old notifications.

Install it in a minute

  1. Download the DMG from the latest release and drag Pullbell to Applications.
  2. Pullbell is signed but not notarized, so clear the quarantine flag once: xattr -dr com.apple.quarantine /Applications/Pullbell.app
  3. Open it, sign in, choose what to watch and allow notifications. It starts at login by default.

Frequently asked questions

Is there an official GitHub menu bar app for Mac?

Not for notifications. GitHub offers the web inbox at github.com/notifications, email and GitHub Mobile. Pullbell is an independent, open-source menu bar app that uses GitHub's public API and is not affiliated with GitHub.

Does Pullbell work on Windows or Linux?

No. Pullbell is a macOS app (macOS 13 or newer, Apple silicon and Intel).

How fast do banners arrive?

Pullbell polls GitHub every 1, 3, 5 or 10 minutes (default 3), so expect a delay of up to that interval. Use Refresh now (⌃⇧⌘G) to check immediately.

Does Pullbell send my data anywhere?

No. It talks only to GitHub's API with your token, which is kept in the macOS Keychain. Its list and a small log without tokens live on your Mac.

Is it free?

Yes. Pullbell is free and open source under the MIT licence.
